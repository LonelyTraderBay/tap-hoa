# Phase 3 — Kế toán thuế GTGT (VAT track)

**Gate: PASS** (Wave A–C)

## Scope

- Inclusive VAT journals when `Store.vatEnabled`
- CoA `1331` / `3331`
- Real `GET /reports/period/vat`
- `GET /reports/period/export.xlsx` (exceljs)
