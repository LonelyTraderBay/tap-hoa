### Chặn môi trường (2026-07-27)

Không chạy được e2e trên máy này: Windows đã chiếm dải TCP **55325–55424**, mà toàn bộ cổng Supabase của `tap-hoa` (55420–55429) nằm trong đó → Docker báo
`bind: An attempt was made to access a socket in a way forbidden by its access permissions`.
Container `supabase_db_tap-hoa` chạy healthy nhưng **không publish port ra host**.
Cần: (a) admin chạy `net stop winnat && net start winnat` + đặt reservation cố định, hoặc (b) dời dải cổng dự án sang vùng trống (vd. 54420–54429), đụng `tap-hoa.identity.ts` + `config.toml` + scripts + docs.

## P0.1 — UsersModule (P0)

**Vấn đề:** `app.module.ts` không có `UsersModule`; `seed.ts` + `create-owner.ts` chỉ tạo `role: owner`. Spec §3.2 định nghĩa 3 vai trò nhưng không có đường tạo Quản lý điểm / Thu ngân ngoài sửa DB tay.

**Thuận lợi:** `User` đã đủ cột (`role`, `canLedger`, `canEinvoice`, `active`) + bảng nối `UserStore` → **không cần migration**.

**DoD:**
- [ ] `GET /users` — owner thấy tất cả; store_manager chỉ thấy user thuộc điểm mình; cashier bị chặn.
- [ ] `POST /users` — owner tạo user (phone, name, password, role, storeIds, canLedger, canEinvoice).
- [ ] `PATCH /users/:id` — sửa name/role/storeIds/cờ quyền/active.
- [ ] `PATCH /users/:id/password` — owner đổi mật khẩu bất kỳ; user tự đổi mật khẩu mình.
- [ ] Chặn: owner cuối cùng không tự vô hiệu hóa; phone trùng → 409; cashier không tự nâng quyền.
- [ ] POS: màn hình quản lý nhân viên (owner-only) trong `features/stores` hoặc `features/users`.
- [ ] e2e `users.e2e-spec.ts` phủ ma trận 3 role + các case chặn.

**Neo:** `apps/api/src/stores/*` (mẫu CRUD + role check), `apps/api/src/auth/auth.service.ts` (bcrypt), `apps/pos_app/lib/features/stores/store_management_page.dart` (mẫu UI owner-only).
